# DimensionMass AI

DimensionMass AI is a cross-platform mobile app for dimension measurement, area/volume calculations, density lookup, and mass estimation using the device camera and local physics models.

Features
- Camera access with local-first processing
- Dimension measurement interface with a live overlay
- Geometry engine for cuboid, cylinder, sphere, cone, and pyramid
- Density database for common materials
- Mass/density solving engine
- Encrypted local storage for measurement history
- Privacy Policy + legal disclaimer screens
- Android and iOS app config for app store release readiness

Quick start
1. Install dependencies
   npm install
2. Start Expo
   npx expo start
3. Run on device/simulator
   npx expo run:android
   npx expo run:ios

Building release APK / AAB / IPA
1. Install EAS CLI
   npm install -g eas-cli
2. Log in to Expo
   eas login
3. Configure your project
   eas build:configure
4. Create a production build profile (already included with EAS if configured)
   eas build -p android --profile production
   eas build -p ios --profile production

Android APK / AAB
- APK: generated by Android build artifacts from EAS or Android Studio
- AAB: generated by EAS Android production build

iOS IPA
- IPA is produced through Xcode signing or EAS iOS production builds after Apple certificate setup

Build requirements
- Android: Android Studio + SDK, or an Expo managed Android build signed by EAS
- iOS: Apple Developer account, provisioning profile, signing certificate, and Xcode
- For real signed release artifacts, use EAS or Xcode with appropriate credentials

Important note
- This project keeps all vision processing local by default.
- It is designed for compliance and production readiness, but physical measurement accuracy depends on the user’s calibration method and device hardware.
